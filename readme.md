\# Secure Login System / Email Spam Detector



\## Description

This project detects whether an email message is spam or not using Python.



\## Features

\- Takes user input

\- Checks email text

\- Classifies as Spam or Not Spam



\## How to Run

1\. Open terminal

2\. Run: python main.py

3\. Enter email text



\## Output

Displays whether the message is spam or not.
